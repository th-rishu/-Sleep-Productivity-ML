# 🛌📈 Sleep Productivity Predictor

This project uses **Machine Learning** to predict a person's productivity based on their sleep hours. The prediction model is built using **Linear Regression**.

---

## 📊 Dataset

The project uses a dataset named:

```text
sleep_productivity.csv
```

The dataset contains information related to sleep duration and productivity levels.

---

## 🛠️ Libraries Used

The following Python libraries were used in this project:

* **NumPy** – Numerical computations
* **Pandas** – Data manipulation and analysis
* **Matplotlib** – Data visualization
* **Scikit-learn** – Machine Learning model development and evaluation

---

## ⚙️ Project Workflow

The following steps were performed:

1. 📂 Loaded and preprocessed the dataset.
2. ✂️ Split the data into training and testing sets.
3. 📏 Scaled the data for better model performance.
4. 🤖 Applied the Linear Regression algorithm.
5. 📊 Evaluated the model using the **R² Score**.

---

## 📈 Model Performance

### R² Score Achieved: **~0.66**

The model achieved an approximate **R² score of 0.66**, indicating a moderate relationship between sleep duration and productivity based on the available dataset.

---

## 🧠 Machine Learning Algorithm

### Linear Regression

Linear Regression is used to identify the relationship between:

* **Input:** Sleep Hours
* **Output:** Productivity

The trained model uses this relationship to predict productivity levels based on new sleep-hour values.
